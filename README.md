# RePlate

Big Data food waste analytics and redistribution platform.

## Overview

FoodLoop analyzes large-scale food waste data using Java, Hadoop MapReduce, and HDFS, and provides analytics and redistribution recommendations through a web platform.

## Objectives

- Analyze food waste patterns at scale
- Identify major sources and categories of food waste
- Identify potentially redistributable food
- Provide data-driven redistribution recommendations
- Explore parallel and distributed data processing

## Technology Stack

- Java
- Hadoop
- HDFS
- MapReduce
- NoSQL Database
- Spring Boot
- React
- Docker
- GitHub Actions
