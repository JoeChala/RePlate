# Contributing to RePlate

## Branches

- `main` — stable project branch
- `development` — active development branch

## Workflow

1. Pull the latest `development` branch.
2. Make your changes.
3. Commit your changes.
4. Push to `development`.
5. Verify that CI passes.
6. The .editorconfig helps prevent Windows/Linux formatting differences.

## Rules

- Do not push directly to `main`.
- Keep commits focused and descriptive.
- Pull the latest `development` before starting work.
- Make sure tests pass before considering work complete.
